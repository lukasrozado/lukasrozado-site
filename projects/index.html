Projetos

Dez sistemas de dados que rodaram, ou ainda rodam, em produção: ingestão contínua, reconciliação contábil, recuperação de falha e modelagem preditiva. Os casos corporativos aparecem de forma anonimizada por sigilo, sem nome de empresa, de cliente ou de contraparte, e sem volume financeiro. O que fica é a decisão de arquitetura, o trade-off e o mecanismo que sustenta o resultado. A única exceção é o dataset da LCK Spring 2024, público no Kaggle e auditável por qualquer pessoa.

Dados financeiros e bancários

Cinco pipelines de ingestão e reconciliação sobre dado transacional, bancário e fiscal.

  • Unified Banking Ledger Platform

    Plataforma unificada de ingestão bancária, PIX, ledger e mesa OTC, com isolamento de estado por domínio e auditor de ciclo de vida.

    Python · PostgreSQL · Azure · SQL

  • High-Concurrency Financial Reconciliation Pipeline

    Pipeline híbrido de ingestão e reconciliação financeira, com auto-cura via anti-join, checkpoint por página e backfill sequencial isolado.

    Python · PostgreSQL · Azure · SQL

  • BaaS & Financial Settlement Data Sink

    Pipeline de integração programática que centraliza liquidação financeira multibancária (BaaS), com sanitização de payload e backfill isolado do checkpoint.

    Python · Azure · REST API · PostgreSQL

  • OTC Desk Reconciliation Pipeline

    ETL diário que reconcilia planilha operacional sem chave primária estável, com fuzzy matching, blindagem de schema e Full Replace.

    Python · PostgreSQL · SQL

  • Fiscal Document Consolidation Pipeline

    Pipeline mensal que baixa XML e PDF de documentos fiscais via API, resolve o dono de cada documento por substring match e consolida por empresa.

    Python · PostgreSQL · REST API

Ativos digitais e blockchain

Três integrações sobre exchange, custódia institucional e leitura direta de nó blockchain.

  • Enterprise Crypto Data Lake: Ingestão Multi-Conta

    Pipeline de ingestão para dezenas de contas institucionais em exchange de cripto, com rate limiter por header oficial e >99,9% de uptime em produção.

    Python · PostgreSQL · Azure · SQL

  • Unified Multi-Chain Ledger Integrator

    Pipeline resiliente para consolidar transações em dezenas de blockchains (EVM e Solana) via RPC, com reconciliação de 100% contra o supply on-chain.

    Python · PostgreSQL · Azure · SQL

  • Institutional Digital Asset Custody Integrator

    Orquestrador de ingestão para custódia institucional de criptoativos, com workspace isolado por credencial e sobreposição de 5min no backfill.

    Python · REST API · Azure · PostgreSQL
